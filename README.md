# 1C AI Dev Tools — Набор инструментов для AI-разработки на 1С

> Готовый набор навыков, конфигураций и инструкций для AI-разработки на платформе 1С:Предприятие 8.3 с использованием OpenCode.

## Что включено

- **79 навыков** для полного цикла разработки на 1С
- **Конфигурация OpenCode** с MCP-серверами и настройками
- **Шаблон проекта** `.v8-project.json` для работы с базами 1С
- **Аналитический отчёт** по инструментам AI для 1С

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/legavaz/skills_1c.git
cd skills_1c
```

### 2. Установка навыков (если клонируете отдельно)

```bash
# Клонировать исходный репозиторий навыков
git clone https://github.com/Nikolay-Shirokov/cc-1c-skills.git tools/cc-1c-skills

# Установить навыки для OpenCode
python tools/cc-1c-skills/scripts/switch.py opencode --project-dir .

# Или установить глобально
python tools/cc-1c-skills/scripts/switch.py opencode --project-dir . --link
```

### 3. Настройка конфигурации

1. Отредактируйте `.v8-project.json` — укажите пути к платформе 1С и базам данных
2. Настройте `opencode.json` при необходимости
3. Запустите OpenCode из корня проекта

## Конфигурация проекта

### .v8-project.json

Основной файл конфигурации. Указывает:
- Путь к платформе 1С
- Параметры подключения к базам данных
- Пути к исходникам конфигурации
- Настройки веб-публикации

Пример минимальной конфигурации:

```json
{
  "v8path": "C:\\Program Files\\1cv8\\8.3.24.1691\\bin",
  "databases": [
    {
      "id": "dev",
      "name": "Разработка",
      "type": "file",
      "path": "C:\\Bases\\MyApp_Dev",
      "user": "Администратор"
    }
  ],
  "default": "dev"
}
```

### opencode.json

Конфигурация OpenCode включает:
- Пути к навыкам
- MCP-серверы (опционально)
- Права доступа
- Ссылки на документацию

## MCP-серверы (опционально)

Для расширенной интеграции можно подключить MCP-серверы:

### BSL Context (справка платформы)

```bash
# Требуется Java 17+
# Скачать: https://github.com/Regsorm/bsl-context/releases
```

### Playwright (браузерная автоматизация)

```bash
npm install -g @anthropic-ai/mcp-server-playwright
```

## Требования

- **Windows** с PowerShell 5.1+
- **Python 3.9+** (для скриптов установки)
- **Node.js 18+** (для `/web-test`)
- **1С:Предприятие 8.3** (для сборки/разборки EPF/ERF)
- **Java 17+** (опционально, для BSL Context)

## Обновление навыков

```bash
cd tools/cc-1c-skills
git pull
cd ../..
python tools/cc-1c-skills/scripts/switch.py opencode --project-dir .
```

## Удаление навыков

```bash
python tools/cc-1c-skills/scripts/switch.py --undo opencode
```

## Использование

1. Опишите задачу своими словами
2. AI-агент автоматически подберёт нужный навык
3. Или вызовите навык напрямую: `/epf-init МояОбработка`
