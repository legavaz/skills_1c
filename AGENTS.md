# Инструкции для AI-агента

## Проект

Набор инструментов и навыков для AI-разработки на платформе 1С:Предприятие 8.3.

## Общие правила

- Всегда проверяй `.v8-project.json` перед 작업ой с базой 1С
- Используй skills из `.opencode/skills/` для операций с XML-файлами 1С
- Не изменяй файлы в `tools/cc-1c-skills/` — это внешний репозиторий
- Перед коммитом проверяй, что `.gitignore` исключает временные файлы

## Работа с 1С

### Конфигурация
- Используй `/cf-*` навыки для работы с корневыми файлами конфигурации
- Используй `/meta-*` навыки для объектов метаданных (23 типа)
- Используй `/cfe-*` навыки для расширений

### Формы
- Используй `/form-*` навыки для управленияляемых форм
- Используй DSL (JSON) для генерации форм через `/form-compile`

### Код
- Все проверки BSL проводи через skills, а не вручную
- Для валидации используй `/epf-validate`, `/cfe-validate` и др.

### Базы данных
- Используй `/db-*` навыки для управления базами
- Всегда делай бэкап перед загрузкой изменений

### Тестирование
- Используй `/web-test` для тестирования через веб-клиент
- Записывай видеоинструкции через `/web-test` с recording

## Безопасность

- Никогда не коммить пароли и ключи
- Используй режимы только для чтения при работе с боевыми базами
- Маскируй персональные данные в логах

## Структура проекта

```
.opencode/skills/     — 79 навыков для 1С
tools/cc-1c-skills/   — исходный репозиторий навыков
.v8-project.json      — конфигурация проекта 1С
opencode.json         — конфигурация OpenCode
```
