# Obsidian + инструменты рисования

Vault: `E:\Обсидиан\Обсидиан` (доступ разрешён через permission external_directory).

## Доступные инструменты

| Задача | Инструмент | Куда сохранять |
|---|---|---|
| Заметки, поиск, wiki-ссылки, frontmatter | Obsidian MCP (`obsidian_*`) | любая папка vault |
| Простые схемы/блок-схемы в тексте заметки | Mermaid-блок кода в markdown | прямо в заметку |
| Рисованные диаграммы с редактированием в Obsidian | Excalidraw `.excalidraw.md` | `E:\Обсидиан\Обсидиан\Excalidraw\` |
| Чертежи, планы, DXF, экспорт PNG/SVG/PDF | DXF MCP (`dxf_*`), workspace `Чертежи` | `E:\Обсидиан\Обсидиан\Чертежи\` |
| Отчёты, дашборды, графики в xlsx | Excel MCP (`excel_*`) | `Чертежи\` или папка заметки |

## Правила интеграции

1. **Каждый визуальный файл привязывай к заметке.** После сохранения файла добавь wiki-ссылку в связанную заметку:
   - изображение: `![[Чертежи/demo-plate.png]]`
   - excalidraw: `![[Excalidraw/Название.excalidraw.md]]`
   - xlsx/dxf: `[[Чертежи/report.xlsx]]`
2. **Именование файлов**: по-русски или по-английски, без спецсимволов; Excalidraw — по шаблону плагина `Drawing YYYY-MM-DD HH.MM.SS.excalidraw.md` или осмысленное имя с тем же расширением.
3. **Бинарные файлы (PNG/SVG/PDF/XLSX/DXF) — только в `Чертежи\`** (исключение: вложения конкретной заметки, если пользователь явно просит рядом с заметкой).
4. **Mermaid**: Obsidian рендерит блоки ```` ```mermaid ```` нативно — для простых схем (flowchart, sequence, gantt, ER, pie) не нужны внешние инструменты. Вставляй блок кода в заметку через `obsidian_write_note` / `obsidian_patch_note`.
5. **Excalidraw-файл** — это markdown плагина Obsidian Excalidraw: frontmatter с `excalidraw-plugin: parsed`, затем секции `## Drawing` с JSON в ```` ```json ```` блоке и `## Text Elements`. Для нового рисунка копируй структуру существующего файла из `Excalidraw\` (прочитай один как образец через `obsidian_read_note`).
6. **DXF MCP**: workspace уже указывает на `Чертежи`; используй `dxf_view` (export/screenshot) чтобы получить PNG/SVG рядом с DXF, затем сошлись на оба из заметки.
7. **Excel MCP**: создавай xlsx через `excel_*`-инструменты с явным путём в vault; после создания — wiki-ссылка в заметку (xlsx не встраивается превью, только ссылка).
8. **Проверка результата**: после сохранения файла убедись через `obsidian_list_directory`, что файл появился в vault, и только потом правь заметку со ссылкой.

## Типовой сценарий «диаграмма к заметке»

1. Найди/прочитай заметку (`obsidian_search_notes` / `obsidian_read_note`).
2. Выбери формат: простая схема → mermaid-блок; нужен интерактив/ручное редактирование → Excalidraw; чертёж → DXF MCP; данные/отчёт → Excel MCP.
3. Создай файл/блок в соответствующей папке vault.
4. Вставь ссылку или встраивание `![[...]]` в заметку через `obsidian_patch_note`.
