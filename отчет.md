## Использование навыков

Навыки активируются автоматически — просто опишите задачу своими словами. Примеры:

- "Создай внешнюю обработку для печати накладной" → `/epf-init`
- "Проанализируй структуру формы документа" → `/form-info`
- "Загрузи конфигурацию из XML" → `/db-load-xml`
- "Опубликуй базу через Apache" → `/web-publish`
- "Протестируй форму через веб-клиент" → `/web-test`

## Контекст для продолжения работы

### Установленные инструменты
- **1C Skills for OpenCode** — 79 навыков для полного цикла разработки на 1С
- **Репозиторий:** `tools/cc-1c-skills/` (можно обновлять через `git pull`)
- **Skills (локально):** `.opencode/skills/` — доступны в этом проекте
- **Skills (глобально):** `~/.config/opencode/skills/` — доступны во всех проектах

### Обновление навыков
```bash
cd tools/cc-1c-skills
git pull
cd ../..
python tools/cc-1c-skills/scripts/switch.py opencode --project-dir .
```

### Удаление навыков
```bash
python tools/cc-1c-skills/scripts/switch.py --undo opencode
```

### Зависимости (PowerShell рантайм)
- Windows с PowerShell 5.1+ (входит в Windows)
- 1С:Предприятие 8.3 — для сборки/разборки EPF/ERF
- Node.js 18+ — для `/web-test` (тестирование через браузер)

### Следующие шаги
1. Настроить `.v8-project.json` для конкретной конфигурации 1С
2. Подключить MCP-сервер (например, `1c_mcp` или `BSL Context`)
3. Начать использовать навыки в работе с 1С
